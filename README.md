# TokenTrail

> **Project status:** Design and planning

TokenTrail is a privacy-first desktop dashboard intended to help people understand their Codex usage. It aims to present available quota windows, token activity, reset times, credits, and related metrics in a clear and approachable way.

The project is currently being designed. Its scope, interface, technology stack, privacy model, and distribution approach are being reviewed before implementation begins.

For the current planning work, see the [product specification](docs/PRODUCT_SPEC.md) and [design decision log](design_decisions.md).
